# Contributing to LinkCheck

Thank you for helping improve the project. All contributions should be authentic,
reviewable and focused on real user needs.

1. Search existing issues before starting new work.
2. For non-trivial features, open an issue describing the problem and the
   proposed approach before implementing it.
3. Fork the repo, create a short-lived branch, and include relevant tests.
4. Run `npm test` before opening a pull request.
5. Explain the behaviour change and any security, accessibility or performance
   implications. Screenshots are welcome for UI changes.

Good first contributions include localization, richer HTML parsing, additional
report formats, accessible dashboard improvements and link check edge cases.

We will not accept automated spam pull requests, fabricated adoption metrics or
changes designed only to inflate contributor counts.
